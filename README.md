# Fessiers aux haltères

Minuteur guidé (une seule page, en français) pour la vidéo de Caroline Girvan
[« at Home GLUTE WORKOUT | Dumbbells Only & Booty Focused »](https://www.youtube.com/watch?v=VjGOiFr5oAk).

- 6 exercices : squat, squat sumo bas, soulevé de terre sumo, soulevé de terre roumain, fente latérale alternée, pont fessier.
- Chaque exercice 3 tours de 45 s d'effort / 15 s de repos : répétitions complètes, pulsations, puis 5 pulsations + 1 rép.
- Bips 3-2-1, annonces vocales, pause / précédent / suivant, écran gardé allumé quand le navigateur le permet.
- Historique de la semaine et poids des haltères utilisés, stockés dans le navigateur (localStorage).

Ouvre `index.html` dans un navigateur, ou publie le dépôt avec GitHub Pages, puis « Ajouter à l'écran d'accueil » sur iPhone.
