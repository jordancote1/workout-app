# Galbe – Fessiers & Taille

Application web (une seule page, en français) pour suivre le programme maison fessiers, cuisses et taille fine.

- Coche chaque série ; un minuteur de repos (75 s par défaut) se lance automatiquement.
- Minuteurs intégrés pour l'aspiration abdominale et la planche.
- Note la charge utilisée (sac lesté, bande élastique) et revois celle de la dernière séance pour la surcharge progressive.
- Suivi hebdomadaire (objectif 3 à 4 séances) et rappel du jour de repos.
- Les données restent dans le navigateur (localStorage).

Ouvre `index.html` dans un navigateur, ou publie le dépôt avec GitHub Pages. Sur téléphone, « Ajouter à l'écran d'accueil » pour l'utiliser comme une app.
